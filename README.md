# Rain Info — landing page

Page d'accueil FR de l'application Rain Info (alertes pluie à la minute). Site statique : `index.html` seul.

- Aperçu local : `python3 -m http.server 8000` puis http://localhost:8000
- Paiement : renseigner les liens Stripe Payment Links dans `PAYMENT_LINKS` (en bas de `index.html`). Sans lien, un message « bientôt disponible » s'affiche.
- Prix affichés (19,99 €/an, 2,99 €/mois) : provisoires, à confirmer.
- Reste à faire : prix définitifs, liens App Store / Google Play, pages légales, mise en ligne.
